# Process Models

38 process models, grouped by capability. Each is described by the objects it calls; internal node graphs were not expanded from XML, so sequences are reconstructed from called rules/records/constants.

## Access Request & Approval (12)
`UAM Initiate User Team Access`, `…Access New`, `UAM Initiate User Team Revoke`, `UAM User Team Request Access Approval`, `…Approval Recent`, `UAM User Team Request Access Revoke`, `…Revoke New`, `UAM Self Grant Access By PM`, `UAM Self Removable By Manager`. Common calls: `UAM_getTeamManager`, task-status/definition constants, Approve/Reject constants, email-body rules, Task Request record. Alerts on exception → `UAM Process Model Alert Receivers`.

## Organization (6)
`UAM Create or Update Organization`, `UAM Select Sub Organization`, `UAM Remove Sub Organization`, `UAM Selecting Or Deselecting Sub Organizations`, `UAM Remove Organization Application`, `UAM Organization Application`. Calls org query rules + hierarchy setter.

## Team & Membership (10)
`UAM Create or Update Team`, `UAM Map Org Team`, `UAM Remove Mapped Organization Team`, `UAM Team Application`, `UAM Mapping/Unmapping Organization User`, `UAM Selecting Or Deselecting Org Teams`, `…Org Users`, `…Teams In The Org`, `…Team Roles`, `…Org Team Roles`.

## Application & Role (5)
`UAM Create Application`, `UAM Application Group`, `UAM Remove Application Group`, `UAM Remove Team Application Roles`, `UAM Selecting Or Deselecting Org Applications`.

## User Lifecycle (5)
`UAM Create Or Update User`, `UAM Activate The User`, `UAM Deactivate The User`, `UAM Remove User`, `UAM Add User To Group`, `UAM Remove User To Group`.

## Cross-cutting
`UAM Send Email` — reusable notification subprocess.

## Error handling / notifications

Every non-trivial process references `UAM_PROCESS_MODEL_ALERT_RECEVIERS` (the alert-receiver group) — the app's convention for routing process exceptions. Email notifications are generated by dedicated rules (`UAM_requestaccess_generateEmailBodyForManager`, `UAM_revokeaccess_generateEmailBodyForApprove`, `UAM_generateEmailBodyForReject`, `UAM_revokeaccess_generateEmailBodyForRejected`, `UAM_revokeaccess_generateEmailBodyForManager`).

## Confidence & Evidence

- **Confidence:** Medium
- **Evidence:** 38 ProcessModel nodes + descriptions, `get_capabilities` member rules/constants, approval-model outgoing edges.
- **Assumptions:** START→gateway→END sequences, swimlanes, and timer/escalation events were not parsed from process XML. No intent summaries.
